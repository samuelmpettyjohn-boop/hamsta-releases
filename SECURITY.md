# Security Policy

Thanks for helping keep Hamsta and its users safe!

## Reporting a vulnerability

Please report security problems **privately**:

1. Go to [github.com/samuelmpettyjohn-boop/hamsta-releases](https://github.com/samuelmpettyjohn-boop/hamsta-releases).
2. Open the **Security** tab.
3. Click **Report a vulnerability**.

Or email **support@hamsta.tv** with "Security" in the subject.

Please **don't open a public issue** for security problems. A private report gives me time to ship a fix before the details are public.

## What to include

- The version you tested (Hamsta, HamstaTV or the server)
- Steps to reproduce the problem
- What an attacker could do with it (the impact)
- Screenshots, logs or a proof of concept if you have them

## Scope

In scope:

- The Hamsta app
- The Hamsta server
- HamstaTV
- The update and release-signing system

Out of scope:

- Servers run by other hosts
- Social engineering
- Denial of service by flooding (spamming requests or traffic)

## Supported versions

Only the latest version gets security fixes. The apps update themselves, so please make sure you're on the newest release before reporting.

## Response

Hamsta is a one-person project, so responses are best effort, but every report is read and answered as soon as possible.
