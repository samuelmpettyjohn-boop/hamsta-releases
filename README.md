# Hamsta™ releases

Downloads for **Hamsta™** (private voice, video and chat for you and your friends) and **HamstaTV™** (clip saving, installed from inside Hamsta; formerly HampterTV).

Grab the newest `Hamsta-Setup-x.y.z.exe` from [Releases](../../releases), or click Download on [hamsta.tv](https://hamsta.tv). It installs Hamsta for your Windows account (no admin needed) in `%LOCALAPPDATA%\Programs\hamsta`, adds desktop and Start menu shortcuts, and updates itself. Uninstall it any time from Windows' Apps list. (Versions before 1.8.0 were a single portable `Hamsta.exe`; they update to the installed version by themselves.)

Every release comes with a `latest.json` that includes a signature. Hamsta checks that signature against the developer's key before it installs any update or HamstaTV, so an untrusted download that was tampered with won't work.
