# Hamsta releases

Downloads for **Hamsta** (private voice, video and chat for you and your friends) and **HampterTV** (clip saving, installed from inside Hamsta).

Grab the newest `Hamsta-x.y.z.exe` from [Releases](../../releases). It's a single portable app; your server host gives you an invite code to sign in.

Every release comes with a `latest.json` that includes a signature. Hamsta checks that signature against the developer's key before it installs any update or HampterTV, so a download that was tampered with won't run.
